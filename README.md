# Low Power VLSI Design Using Clock Gating

## Overview
This project implements an 8-bit synchronous counter and a clock-gated 8-bit counter using Verilog HDL. The objective is to reduce dynamic power consumption by minimizing unnecessary clock switching activity through clock gating.

## Features
- 8-bit Normal Counter
- 8-bit Clock-Gated Counter
- Verilog HDL implementation
- Functional simulation using Xilinx Vivado
- Switching activity analysis
- Power analysis and comparison

## Tools Used
- Verilog HDL
- Xilinx Vivado 2025.2

## Files
- `normal_counter.v` – 8-bit normal counter
- `clock_gated.v` – Clock-gated counter
- `testbench.v` – Testbench for simulation

## Results
- Verified functionality through behavioral simulation.
- Generated VCD file for switching activity analysis.
- Compared power reports of normal and clock-gated designs.
- Demonstrated reduction in unnecessary switching activity using clock gating.
